# QL_KTX - Hệ thống quản lý ký túc xá

Dự án quản lý ký túc xá sinh viên.

## Công nghệ
- Frontend: React + Vite
- Backend: Django REST Framework
- Database: MySQL

## Cấu trúc
- `frontend/`: giao diện người dùng
- `backend/`: API và xử lý nghiệp vụ
- `database/`: câu lệnh SQL và dữ liệu mẫu
- `docs/`: tài liệu dự án
